# Potions Plugin Hello World

A minimal "hello world" plugin for the Potions system, designed to serve as a registry integrity check.

## Purpose

This plugin exists to validate that the Potions Plugin Registry CI workflows function correctly. It provides a real, accessible GitHub repository with a valid Potionfile that can be referenced by example manifests in the registry.

## Structure

- `Potionfile` - Plugin manifest defining the plugin metadata
- `README.md` - This file
- `LICENSE` - MIT License

## Usage

This plugin is not intended for production use. It serves as a test fixture for the Potions Plugin Registry validation workflows.
